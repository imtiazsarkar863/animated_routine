# 🎬 Video + Image Overlay

A simple fullscreen web project that combines a looping background video with an image overlay and background audio.

## ✨ Features

* Fullscreen looping video
* Background audio
* Transparent image overlay
* CSS contrast, brightness, and invert effects
* Responsive fullscreen layout
* Autoplay and preload support
* No page scrolling

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript

## 📁 Project Files

```text
├── index.html
├── vdo.mp4
├── vdo_mobile.mp3
└── img.jpeg
```
